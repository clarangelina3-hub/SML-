Dataset Wine Quality (6.497 baris) dari UCI Machine Learning Repository yang berisi karakteristik fisikokimia wine merah dan wine putih dari wilayah Vinho Verde, Portugal. Setiap sampel memiliki 11 variabel prediktor serta 1 variabel target berupa skor kualitas (quality) dari penilaian sensorik para ahli. Tujuan tugas ini adalah mengelompokkan wine berdasarkan kemiripan sifat kimianya. Ini bertujuan untuk melihat pola alami yang ada dalam data dan juga untuk membantu dalam menganalisis kualitas wine dengan lebih baik.
